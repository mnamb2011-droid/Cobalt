# Cobalt Remote 1.1 — الملفات المعدلة

- واجهة تحكم مدمجة مع لوحة لمس للمؤشر وأزرار الاتجاهات والوسائط والصوت.
- بحث تلقائي عن خدمة LG webOS عبر Android NSD مع إبقاء إدخال IP اليدوي.
- إدخال النص باستخدام لوحة مفاتيح Android وإرساله إلى حقل التلفزيون النشط.
- عرض قائمة التطبيقات بأيقوناتها عند توفر رابط الأيقونة من التلفزيون.
- تخزين مفتاح الاقتران مشفرًا باستخدام Android Keystore (AES/GCM).
- تثبيت شهادة TLS بطريقة TOFU: تُحفظ بصمة الشهادة بعد أول اتصال، ويُرفض اختلافها لاحقًا.
- يعيد GitHub Actions بناء المجلدات من الملفات المسطحة وفق `project-layout.yml`.

## تنبيه اختبار

لم يُختبر الاكتشاف أو حركة المؤشر أو أوامر التطبيقات على تلفزيون فعلي في هذه الحزمة. اكتشاف NSD يعتمد على أن يعلن التلفزيون خدمة `_webos-second-screen._tcp`. أول اتصال TLS يثق بالشهادة التي يقدمها التلفزيون؛ لذلك نفّذ الاقتران الأول على شبكة موثوقة. عند تغيير التلفزيون أو إعادة إصدار شهادته، امسح الاقتران بعد التحقق من الجهاز.
